Introdução

A sua privacidade é importante para nós. Esta Política de Privacidade explica como o aplicativo ACAL coleta, usa, compartilha e protege suas informações pessoais.

Ao usar o ACAL, você concorda com os termos desta política. Se você não concordar com nossas práticas de privacidade, por favor, não use o aplicativo.

1. Dados Coletados

1.1 Dados Fornecidos Diretamente por Você

  • Informações de Conta: Nome, email, senha (criptografada), informações de perfil
  • Conteúdo do Usuário: Documentos, faturas, anotações e outras informações que você insere no app
  • Dados de Comunicação: Mensagens, sugestões e feedback que você nos envia

1.2 Dados Coletados Automaticamente

  • Dados do Dispositivo: Tipo de dispositivo, sistema operacional, versão do app, identificador único
  • Dados de Uso: Funcionalidades utilizadas, frequência de uso, duração das sessões
  • Dados de Localização: Apenas se você conceder permissão explícita (opcional)
  • Dados de Diagnostiço: Logs de erro, crash reports para melhorar a estabilidade
  • Cookies e Tecnologias Similares: Para melhorar sua experiência de uso

1.3 Permissões do Dispositivo

Dependendo das funcionalidades que você usar, o app pode solicitar as seguintes permissões:

  • Câmera: Para capturar fotos/documentos (opcional)
  • Galeria/Armazenamento: Para acessar e fazer upload de arquivos
  • Contatos: Para compartilhamento de informações (opcional)
  • Localização: Apenas se você ativar recursos que dependem de geolocalização

Você pode revogar essas permissões a qualquer momento nas configurações do seu dispositivo.

2. Finalidade da Coleta

Coletamos e usamos seus dados para:

  • Fornecer Serviços: Funcionar corretamente e entregar as funcionalidades do ACAL
  • Melhorar o App: Entender como você usa o app para fazer melhorias
  • Segurança: Proteger sua conta contra acesso não autorizado e detectar fraudes
  • Comunicação: Enviar notificações, atualizações e respostas a suas solicitações
  • Análise: Compilar dados estatísticos anônimos sobre uso e desempenho
  • Conformidade Legal: Cumprir leis e regulamentos aplicáveis

3. Compartilhamento com Terceiros

3.1 Serviços de Terceiros

Usamos os seguintes serviços terceirizados, que podem acessar dados limitados:

  • Firebase (Google): Para autenticação, armazenamento em nuvem e analytics
  • Serviços de Análise: Para entender padrões de uso e melhorar funcionalidades
  • Provedores de Pagamento: Se o app tiver compras, dados são compartilhados apenas para processar transações

3.2 Quando Compartilhamos Dados

Podemos compartilhar seus dados quando:

  • Você concede permissão explícita
  • Requerido por lei ou processo legal
  • Necessário para proteger a segurança e direitos do app
  • Em caso de fusão, aquisição ou venda de ativos (você será notificado)

3.3 Dados Compartilhados Entre Usuários

Se o app permitir colaboração ou compartilhamento, os dados que você compartilha explicitamente estarão visíveis para os usuários designados. Você é responsável pelos dados que compartilha.

4. Armazenamento e Segurança

4.1 Onde Armazenamos Seus Dados

  • Servidores Locais: Alguns dados são armazenados no seu dispositivo (offline)
  • Nuvem: Dados sincronizados são armazenados em servidores seguros (Firebase/Google Cloud)
  • Backups: Mantemos backups para recuperação em caso de perda de dados

4.2 Medidas de Segurança

  • Criptografia de dados em trânsito (HTTPS/TLS)
  • Criptografia de dados em repouso onde aplicável
  • Autenticação segura (senhas criptografadas)
  • Acesso restrito aos dados (apenas funcionários autorizados)
  • Monitoramento contínuo de ameaças de segurança

4.3 Retenção de Dados

Mantemos seus dados enquanto sua conta estiver ativa. Se você deletar sua conta, seus dados serão removidos dentro de 30 dias, exceto quando exigido legalmente manter registros.

5. Seus Direitos

Você possui os seguintes direitos em relação aos seus dados pessoais:

  • Direito de Acesso: Solicitar cópia de todos os seus dados pessoais
  • Direito de Retificação: Corrigir dados imprecisos ou incompletos
  • Direito de Exclusão: Deletar sua conta e dados associados
  • Direito de Portabilidade: Receber seus dados em formato estruturado
  • Direito de Oposição: Opor-se ao processamento de seus dados em certos casos
  • Direito de Revogar Consentimento: Retirar autorização para coleta/uso de dados
Como Exercer Seus Direitos:
Para exercer qualquer desses direitos, entre em contato conosco através do email fornecido na seção de contato. Responderemos em até 30 dias.

6. Proteção de Menores

O ACAL não é direcionado para menores de 13 anos. Não coletamos intencionalmente dados pessoais de crianças menores de 13 anos.

Se descobrirmos que coletamos dados de uma criança menor de 13 anos sem consentimento dos pais/responsáveis, tomaremos medidas imediatas para deletar essas informações.

Para usuários entre 13 e 18 anos (menores de idade em alguns países), fornecemos proteções adicionais e recomendamos supervisão dos pais/responsáveis.

7. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente para refletir mudanças em nossas práticas, tecnologia ou legislação.

Notificaremos você sobre alterações materiais através de:

  • Email para o endereço registrado em sua conta
  • Notificação destacada no app
  • Atualização da data de "Última atualização" nesta página

Seu uso continuado do app após as alterações constitui sua aceitação dos novos termos.
